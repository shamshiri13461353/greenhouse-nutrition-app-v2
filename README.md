# اپلیکیشن تغذیه گلخانه v2
نسخه مستقل و آزمایشی؛ مخزن و APK قبلی را تغییر نمی‌دهد.

## امکانات
- اهداف عناصر N، P، K، Ca، Mg و S بر حسب mg/L
- محاسبه نیترات کلسیم در مخزن B و سهم N آن
- حل‌گر تقریبی کودهای مخزن A، ویرایش آنالیز کودها
- پایش EC/pH گلخانه و پشتیبان‌گیری JSON
- رابط فارسی راست‌چین

## هشدار مهم
این بسته نمونه اولیه است و فرمول آماده مصرف تجاری نیست. درصدها باید با برچسب واقعی کود تطبیق داده شوند. حل عددی به معنی تأیید انحلال‌پذیری یا سازگاری شیمیایی نیست. کلسیم را با فسفات/سولفات در مخزن غلیظ مخلوط نکنید. قبل از مصرف عملی، آب، دما، pH، غلظت و رسوب‌پذیری بررسی شود.

## بارگذاری
ZIP را استخراج کنید و همه محتویات آن را در مخزن جدید `greenhouse-nutrition-app-v2` از مسیر Add file → Upload files بارگذاری و Commit کنید. سپس Actions را باز کنید و گردش‌کار Build Android APK را اجرا کنید. APK در بخش Artifacts قابل دریافت است.
